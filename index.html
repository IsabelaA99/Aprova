Estudo para o concurso de Analista de TI do Banco Central, com o edital BCB nº 1/2024 (Cebraspe) como base, enquanto o novo edital não sai. O Radar é uma estimativa; os horários do cronograma são sugestões. Os flashcards, as discursivas e as fichas de normas são autorais, no estilo Cebraspe: confira a redação oficial das normas. Questões de bancos pagos não são copiadas: use o botão "Treinar no QConcursos" de cada assunto. Os recursos com ✦ usam o Claude (Sonnet 5.5, esforço médio) e gastam o seu limite de uso.
